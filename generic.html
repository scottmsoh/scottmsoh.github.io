Customer Propensity Analysis for Sales Forecasting and Targeting



Project Overview

In this project, I developed a machine learning model to predict future customers based on various company characteristics and financial data. The goal was to create an effective customer targeting system that could identify potential customers with high conversion probability.

Data Collection and Preparation

Dataset Characteristics

  • Training set: 4,000 samples
  • Test set: 1,000 samples
  • Features: 56 different variables
  • Data sources:
    • Current customer data (1K) and non-converted leads (3K) from Folloze
    • Financial information from WRDS (Wharton Research Data Services)
    • Historical SEC filing data

Data Cleaning Process

The data cleaning process involved handling multiple types of features:

  1. Company Profile Features
    • Reduced from 30 to 14 essential attributes
    • Included address information, postal codes, business descriptions, and GIC industry classifications
  2. Financial Features
    • Streamlined from 100 to 36 key indicators
    • Removed redundant metrics (e.g., duplicate EPS measures)
    • Handled special cases for non-financial companies
  3. Missing Value Treatment
    • Implemented KNN imputation for critical features
    • Used SPCSRC rating system (등급) with D-A+ scaling
    • Applied median imputation for right-skewed distributions
  4. Outlier Management
    • Applied IQR method (25th and 75th percentiles)
    • Used multiplier of 3 for boundary determination
    • Calculated lower bounds using Q1-multiplier*IQR formula

Exploratory Data Analysis

The EDA phase focused on:

  • Visual analysis of price relationships with other features
  • Comprehensive correlation analysis to understand feature relationships

Feature Engineering

Feature Selection and Creation

  1. Categorical Features
    • Used Ridge and Lasso regression to identify top 27 features
    • Implemented one-hot encoding for categorical variables
  2. Size Feature Development
    • Addressed multicollinearity using Variance Inflation Factor (VIF)
    • Applied Principal Component Analysis (PCA) for dimensionality reduction
  3. New Feature Creation
    • Report Filing Delay (RFD): Calculated as the difference between financial date and actual period end date
    • GAP Preliminary Official (GPO): Measured time between final and preliminary dates
    • Time-based features: Computed relative to current date

Model Development

Data Preprocessing

  • Standardization: Applied to features with different scales
  • Normalization: Log transformation for highly skewed data (Amount, age, dpq, gpo, salesq)

Model Selection

Tested multiple algorithms:

  • Decision Trees
  • Random Forest
  • Logistic Regression
  • Support Vector Machine (SVM)
  • XGBoost
  • LightGBM
  • Ensemble voting methods
  • Ada+DecisionTree

The best performance was achieved using XGBoost with SMOTE for handling imbalanced data and outlier treatment.

Results

The final model achieved impressive performance metrics:

  • Recall: 0.9
  • Precision: 0.9
  • F1-Score: 0.9

These results indicate strong predictive capability for identifying potential customers.

Reflections and Future Improvements

Some potential areas for enhancement:

  • Further exploration of customer historical data could provide additional insights
  • Investigation of private customer data integration possibilities
  • Consideration of alternative feature engineering approaches

This project successfully demonstrated the potential of machine learning in customer targeting and sales forecasting, providing a robust foundation for future business development efforts.
